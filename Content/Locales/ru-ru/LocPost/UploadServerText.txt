﻿Вы должны авторизоваться чтобы открыть файл для загрузки на этот сервер.
Используйте команду "upload [LOCAL_FILENAME]" для загрузки файлов


НАПОМИНАНИЕ: Файлы, загружаемые с [scp] загружаются в ~/home
(or ~/bin for executables)
Для загрузок отсюда нужно указать маршрут, такой как:  home/[FILENAME]
Кнопка Tab может использоваться для автозаполнения маршрута и названий локальных файлов для загрузки.
